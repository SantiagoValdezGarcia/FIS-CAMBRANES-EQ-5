# Historias de Usuario - EpilepsiApp

## Pantalla de Inicio
1. **Botón de emergencia**  
   - Como usuario con epilepsia  
   - Quiero presionar un botón de emergencia  
   - Para enviar una alerta a mis contactos con mi ubicación  

2. **Registrar crisis**  
   - Como usuario  
   - Quiero registrar el tipo, duración y síntomas de mi crisis  
   - Para llevar un control de mis episodios  

3. **Agregar medicamento**  
   - Como paciente  
   - Quiero agregar el nombre, dosis y horario de mis medicinas  
   - Para recibir recordatorios y no olvidar tomarlas  

4. **Marcar medicamento como tomado u omitido**  
   - Como usuario  
   - Quiero marcar si ya tomé o no mi medicamento  
   - Para mantener actualizado mi control diario  

---

## Pantalla de Historial
5. **Ver historial de registros**  
   - Como usuario  
   - Quiero ver una lista con mis crisis, medicaciones y emergencias pasadas  
   - Para revisar mi evolución y frecuencia de eventos  

6. **Filtrar historial**  
   - Como usuario  
   - Quiero filtrar los registros por tipo (crisis, medicación o emergencia)  
   - Para encontrar fácilmente la información que necesito  

---

## Pantalla de Reportes
7. **Generar reportes**  
   - Como paciente  
   - Quiero generar un reporte con mis estadísticas de salud  
   - Para compartirlo con mi médico o analizar mi progreso  

8. **Exportar datos**  
   - Como usuario  
   - Quiero exportar mis datos en PDF, CSV o JSON  
   - Para tener copias o analizarlos en otras herramientas  

9. **Ver estadísticas**  
   - Como usuario  
   - Quiero visualizar mis porcentajes de cumplimiento, tipos de crisis y alertas  
   - Para entender mejor mi estado de salud  

---

## Pantalla de Perfil
10. **Ver perfil**  
    - Como usuario  
    - Quiero consultar mi información personal, médica y contactos de emergencia  
    - Para mantener mis datos actualizados  

11. **Editar información**  
    - Como usuario  
    - Quiero editar mi información personal o médica  
    - Para que mis registros estén correctos y completos  

12. **Editar contactos de emergencia**  
    - Como usuario  
    - Quiero actualizar o agregar contactos de emergencia  
    - Para asegurarme de que las alertas se envíen a las personas correctas  

---

## Funciones Adicionales
13. **Modo sin conexión**  
    - Como usuario  
    - Quiero poder usar la app incluso sin internet  
    - Para registrar datos o acceder a mi información en todo momento  

14. **Instalar la app (PWA)**  
    - Como usuario  
    - Quiero instalar la aplicación en mi dispositivo móvil  
    - Para acceder fácilmente sin abrir el navegador
