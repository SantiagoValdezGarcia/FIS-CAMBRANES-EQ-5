# **Competencias Genéricas en el Desarrollo de EpilepsiApp**

El desarrollo de **EpilepsiApp** promueve competencias genéricas esenciales para la formación integral en Ingeniería de Software. A través de actividades reales del proceso de desarrollo, se fortalecen habilidades relacionadas con la colaboración, comunicación, análisis crítico, autonomía y responsabilidad social.

## **Relación entre Actividades y Competencias Genéricas**

| **Actividad del Proyecto** | **Competencias Genéricas Promovidas** |
| ----------------------------- | ----------------------------------------- |
| **Trabajo en equipo multidisciplinario** (desarrolladores, UX/UI, product owner, scrum master). | **Colaboración efectiva** |
| **Documentación y comunicación** en requisitos, reportes, pruebas y presentaciones. | **Expresión clara oral y escrita** |
| **Análisis crítico y decisiones de diseño** en la definición del problema y priorización de funcionalidades. | **Pensamiento crítico**, creatividad, resolución de problemas y juicio profesional responsable. |
| **Compromiso con la calidad** mediante revisión, pruebas y mejora continua. | **Ética profesional** |
| **Gestión autónoma de tareas y roles** dentro de Scrum. | **Autonomía** |
| **Consideración del contexto real del usuario** (epilepsia, necesidades reales, sensibilidad social). | **Empatía**, responsabilidad social y visión integral del impacto del producto. |

---

## **Conclusión**

El proyecto **EpilepsiApp** constituye un entorno formativo que impulsa el desarrollo de **competencias genéricas clave** para la práctica profesional del ingeniero en software. Las actividades realizadas fortalecen un perfil integral capaz de responder a necesidades reales con calidad, responsabilidad y sensibilidad social.

---

# **Competencias Específicas en el Desarrollo de EpilepsiApp**

El desarrollo de **EpilepsiApp** permite aplicar y fortalecer de manera directa las **competencias específicas** establecidas en el programa de la asignatura *Ingeniería de Software* (UADY). A través de tareas reales de análisis, diseño, modelado, desarrollo y validación, el equipo integró conocimientos técnicos y metodológicos fundamentales para la construcción de software de calidad.

---

## **Relación entre Actividades y Competencias Específicas**

| **Actividad del Proyecto** | **Competencias Específicas Promovidas** |
| ------------------------------ | ------------------------------------------- |
| **Análisis de requisitos funcionales y no funcionales**, entrevistas, identificación del problema y definición del alcance. | **CE1. Aplicar técnicas de análisis para identificar y especificar requisitos de software.** |
| **Modelado** (casos de uso, actividades, secuencia) basado en los requisitos de EpilepsiApp. | **CE2. Emplear modelos y herramientas de representación para describir la estructura y comportamiento del sistema.** |
| **Diseño de arquitectura y prototipado UX/UI**, organización de componentes, flujos y lógica del sistema. | **CE3. Diseñar soluciones de software alineadas a requisitos, buenas prácticas e interfaces centradas en el usuario.** |
| **Implementación de funcionalidades** siguiendo buenas prácticas y GitHub como entorno de control de versiones. | **CE4. Desarrollar software aplicando principios de calidad, modularidad y uso adecuado de herramientas de implementación.** |
| **Pruebas y validación**, documentación de incidencias y ajustes iterativos del producto. | **CE5. Aplicar técnicas de verificación y validación para asegurar la calidad del sistema.** |
| **Gestión del proyecto mediante Scrum**, organización en sprints, actividades de seguimiento y retrospectivas. | **CE6. Utilizar metodologías y marcos de trabajo para la gestión del proceso de desarrollo de software.** |

---

## **Conclusión**

El proyecto **EpilepsiApp** permitió que el equipo desarrollara y consolidara competencias específicas clave en Ingeniería de Software. Gracias a la naturaleza iterativa del proyecto y al uso de marcos formales como **Scrum** y buenas prácticas de desarrollo, los estudiantes integraron conocimientos teóricos con experiencias reales de producción.
