# 🧠 **EpilepsiApp**

**EpilepsiApp** es una aplicación móvil para personas con epilepsia que facilita el **control del tratamiento**, el **registro de crisis** y la **atención en emergencias** mediante herramientas digitales seguras y accesibles.

---

## Objetivo
Mejorar la calidad de vida de los pacientes con epilepsia mediante:
- Recordatorios de medicación.
- Registro de crisis con evidencia multimedia.
- Alertas automáticas a contactos de emergencia.
- Comunicación más eficiente con el médico tratante.

---

## Funcionalidades
- **Registro y seguimiento de medicación** con notificaciones.
- **Diario de crisis** con fotos, audios o videos.
- **Botón de emergencia** que envía ubicación en tiempo real.
- **Historial compartible** con el médico.
